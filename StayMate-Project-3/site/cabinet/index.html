Інформація для гостей

ШІ-адміністратор відповідає на питання гостей САМЕ на основі цих даних. Якщо поле порожнє, а гість про це спитає — бот чесно скаже, що уточнить, і передасть питання вам (в «Ескалації»), а не вигадає відповідь. Заповніть те, що встигаєте — решту можна дозаповнити пізніше.

Канали зв'язку

Підключіть один або кілька каналів — ШІ-адміністратор відповідає однаково скрізь, використовуючи одні й ті самі дані про номери й ціни.

Telegram Не підключено

Створіть власного бота через @BotFather у Telegram (2 хвилини) і вставте отриманий токен нижче.

Viber Не підключено

Створіть публічний акаунт (бота) на partners.viber.com і вставте токен API нижче. Заявку на комерційне схвалення подано — до відповіді Viber бот вже приймає повідомлення в тестовому режимі.

Сайт готелю Готово до використання

Не потребує окремого підключення. Вставте цей код перед </body> на сайті вашого готелю — з'явиться кнопка чату з ШІ-адміністратором.

WhatsApp Не підключено

Підключення через WhatsApp Cloud API (Meta). Вставте Phone Number ID і Access Token із вашого додатка в Meta for Developers — ми одразу перевіримо їх реальним запитом до Meta.

Instagram Не підключено

Директ Instagram підключається через той самий Meta-додаток, що й WhatsApp/Messenger. Вставте Instagram Business Account ID і Access Token.

Facebook Messenger Не підключено

Вставте Page Access Token сторінки вашого готелю з Meta for Developers — ID сторінки визначиться автоматично.
