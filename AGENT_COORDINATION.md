# Координация Codex и Claude Code

## Как взять задачу

1. Обновите свою рабочую ветку и посмотрите актуальный main.
2. Откройте общую launch-board и посмотрите блок «Сейчас в работе».
3. Выберите свободную P0, а если таких нет — свободную P1.
4. Сделайте CLAIM TASK, указав себя, короткое описание текущей работы и список файлов.
5. Начинайте код только при результате CLAIM_SUCCESS.

Codex использует идентификатор codex, Claude Code — claude_code. Оба работают через обычную авторизованную сессию Supabase: service-role ключ для этого не нужен и не используется.

## Как избежать конфликтов

Если задача уже занята другим агентом, claim возвращает TASK_ALREADY_CLAIMED. Если её файлы пересекаются с файлами активной задачи другого агента, claim возвращает FILE_CONFLICT. В обоих случаях выберите другую задачу или дождитесь владельца.

## Как закончить

Проверьте работу, прогоните нужные тесты, сделайте отдельный commit и сохраните его SHA в board. Затем переведите задачу в «Ждёт проверки». После настоящего PASS — в «Готово».

## Как передать задачу

Владелец может снять назначение, назначить Codex или Claude Code, передать задачу, поставить её на паузу или вернуть в очередь. Это сохраняется в истории. Старый lock не освобождается сам: если агент давно не обновлялся, board только показывает предупреждение владельцу.
